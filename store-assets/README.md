# Store assets for Play Store listing

This directory contains placeholder metadata and instructions for the Play Store release. Replace the placeholder files and URLs with your real assets (icon, feature graphic, screenshots, and promo video) before uploading to the Play Console.

Recommended filenames (place files here):
- icon_512.png (512x512 PNG)
- feature_graphic.png (1024x500 PNG)
- screenshots/phone_ss1.png (1080x1920 or 1440x2560)
- screenshots/phone_ss2.png
- screenshots/tablet_ss1.png (1920x1080)

Placeholder assets (these are URLs you can download or use temporarily):
- Placeholder icon: https://via.placeholder.com/512.png?text=Icon+512x512
- Placeholder feature graphic: https://via.placeholder.com/1024x500.png?text=Feature+Graphic
- Placeholder screenshot: https://via.placeholder.com/1080x1920.png?text=Screenshot

How to use
1. Create the required image files locally and place them in this directory.
2. Update `store-metadata.json` with your real package name, URLs and asset filenames.
3. Upload the images and metadata in Play Console when creating a new release.
