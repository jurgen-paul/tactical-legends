# Screenshots placeholder instructions

Create a `screenshots/` directory under `store-assets` and add at least two phone screenshots:
- store-assets/screenshots/phone_ss1.png
- store-assets/screenshots/phone_ss2.png

Recommended sizes:
- Phone portrait: 1080x1920 (or 1440x2560)
- Phone landscape: 1920x1080

You can use the placeholder screenshot at:
