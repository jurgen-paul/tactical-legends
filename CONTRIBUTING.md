# Contribution Guidelines for Tactical Legends

Thank you for your interest in contributing to the Tactical Legends project! We appreciate your help and aim to make the contribution process as smooth as possible. Below are the guidelines to follow when contributing to our project.

## Code of Conduct
We expect all contributors to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md). This document outlines the standards for behavior that we expect from all participants in our community.

## Getting Started
To get started, please fork the repository and clone it to your local machine:

```bash
git clone https://github.com/jpaul8282/tactical-legends.git
```

Once you have a local copy, you can create a branch for your changes:

```bash
git checkout -b your-feature-branch
```

## How to Contribute
1. **Make your changes:** Implement your feature or fix any bugs you have identified.
2. **Write tests:** Make sure that your changes are covered by tests where applicable.
3. **Commit your changes:** Commit your changes with a clear and descriptive message. For example:
   ```bash
   git commit -m "Add new feature to enhance user experience"
   ```
4. **Push your changes:** Push your changes to your forked repository:
   ```bash
   git push origin your-feature-branch
   ```
5. **Open a Pull Request:** Go to the original repository on GitHub and open a pull request. Be sure to describe your changes and why they are useful.

## Development Guidelines
- Follow the existing code style.
- Keep your commits unambiguous and clean.
- Make sure your code is tested and does not break anything.
