# Common Platform Enumeration (CPE)

CPE is a structured naming scheme for IT systems, software, and packages. It provides a standard way of identifying and classifying software and hardware.

## CPE Naming Format
A CPE name consists of several components:
- **Part**: Defines the type of the product – application, operating system, or hardware.
- **Vendor**: Name of the vendor or publisher of the product.
- **Product**: Name of the product.
- **Version**: Version number of the product.
- **Update**: Update or patch level, if applicable.

## Example CPE Name
For example, here’s a sample CPE name for a web browser:
```
 cpe:2.3:a:microsoft:internet_explorer:11.0:*:*:*:*:*:* 
```

This CPE name indicates Microsoft's Internet Explorer version 11.0.
