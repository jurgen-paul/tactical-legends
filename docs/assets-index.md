# Asset Index and Accessibility

This page points to the store-assets accessibility mappings and OCR transcripts for the Tactical Legends repository.

- Alt text mappings: /store-assets/alt-texts.md
- Image transcripts (OCR): /docs/ocr-image-transcripts.md

How to use
1. When adding images to the repo, reference alt text from the alt-texts.md file.
2. For detailed captions or accessibility descriptions, include the OCR transcript near the image in your docs or as a caption block.
