# Annotated assets index

This file lists the annotated SVG assets generated for QA and documentation. Each SVG uses a placeholder background image; replace the background with your final screenshots for production.

Files added:
- store-assets/annotated/annotated-ss4.svg — AI Tactical Brief annotations (dialog, cursor)
- store-assets/annotated/annotated-ss5.svg — Squad Bay annotations (nav, squad card, stats)
- store-assets/annotated/annotated-ss6.svg — Cinematic quote annotations (quote, attribution, chapter selector)
- store-assets/annotated/annotated-ss7.svg — Chapter title annotations (title, bottom controls)

How to update backgrounds:
1. Replace the placeholder image URL inside the `<image href="..." />` tag with your real asset path (e.g., ../ss4.png).
2. Commit the updated SVG file. The overlays (rectangles, arrows, labels) will remain and align to the same coordinates.
