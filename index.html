Quick Start Guide

Follow these steps to compile, configure, and launch the Tactical Legends project.

1

Clone Repository

Download the source code and documentation assets from GitHub.

2

Install Dependencies

Ensure CMake, C++ toolchain, SDL2 libraries, and Node.js are installed.

3

Build & Configure

Generate native build files with CMake or launch the web preview server.

4

Launch & Command

Execute the game client or inspect tactical schemas via the web terminal.

# 1. Clone repository
git clone https://github.com/jurgen-paul/tactical-legends.git
cd tactical-legends

# 2. Web Applet Dev Server (AI Studio / Node.js)
npm install
npm run dev

# 3. Native C++ / CMake Engine Build (Linux / Ubuntu)
sudo apt update && sudo apt install cmake g++ libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev
mkdir build && cd build
cmake ..
make -j$(nproc)
./tactical_legends
